# Syed Ijaz Ul Haq - Personal Academic Website

A clean, modern academic personal website built with HTML, CSS, and JavaScript, matching the Hugo Academic theme style.

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | Main page with your information |
| `style.css` | Styling matching Chen Liu's Hugo Academic template |
| `script.js` | Interactivity (nav, scroll, career card toggle) |

## 🚀 Quick Start

1. **Preview locally**: Double-click `index.html` to open in your browser
2. **Add your photo**: Replace the placeholder image with your actual photo
3. **Update links**: Add your Google Scholar, LinkedIn, etc. URLs
4. **Deploy**: Upload to GitHub and enable GitHub Pages

## ✏️ Customization Guide

### Add Your Photo
Replace this line in `index.html`:
```html
<img src="https://via.placeholder.com/360x360?text=Your+Photo" ...>
```
With:
```html
<img src="images/your-photo.jpg" ...>
```

### Update Social Links
Find the `.social-links` section and update the `href` attributes with your actual profile URLs.

### Add More Publications
Copy an existing `.pub-entry` block and modify the content.

### Deploy to GitHub Pages
1. Create a repo named `your-username.github.io`
2. Push these files
3. Enable Pages in Settings → Pages
